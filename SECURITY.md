# Security policy

RoadForge is an independent research and engineering project. Please do not publish credentials, private datasets, model files with restricted terms, or CARLA server endpoints in issues.

For a suspected security vulnerability involving unsafe file handling, path traversal, dependency compromise, or execution behavior, contact the repository maintainer privately through the GitHub profile rather than opening a public issue with exploit details.

This project is not designed or certified as a safety-critical autonomous-driving controller.
